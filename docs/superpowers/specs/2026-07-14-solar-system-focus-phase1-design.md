# 太阳系近景阶段 1 设计

## 目标

让所有太阳系行星、矮行星、已定义卫星和哈雷彗星都能进入近景观测，并按类型给出可区分的基础高细节模型。

## 架构

- 统一渲染器：`js/specials/solarSystemFocusRenderer.js`
- 数据驱动：各天体增加 `effectType`
- 路由：`SpecialBodyFactory` 识别太阳系类型
- 远看几何不变，仅近景加载高细节

## effectType

| 类型 | 对象 |
|---|---|
| `planet-terrestrial` | 水金地火 |
| `planet-gas` | 木土 |
| `planet-ice` | 天海 |
| `dwarf-planet` | 谷神/冥王/阋神 |
| `moon` | 全部已定义卫星 |
| `comet` | 哈雷 |

## 近景视觉（阶段 1）

- 岩质：高分辨率程序化表面 + 可选大气辉光
- 气态：云带 + 自转 + 大红斑提示（木星）
- 冰巨：淡青色/深蓝云层 + 弱环（天王星）
- 矮行星：冰岩表面
- 卫星：陨坑/冰面差异
- 彗星：彗核 + 彗发 + 动态彗尾

## 验收

- 任意太阳系天体可进近景
- 木星/土星/地球/哈雷一眼可区分
- 退出后状态恢复正常
- 远看太阳系帧率不明显下降
