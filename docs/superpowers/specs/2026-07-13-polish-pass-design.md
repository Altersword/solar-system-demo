# 最小修复轮设计

## 目标

在不推翻现有架构的前提下，修复已知体验问题，提升近景可用性与文档可信度。

## 范围

1. Loading 遮罩在场景初始化后可靠关闭，失败时不永久遮挡。
2. 近景观测按天体类型自动调整时间倍率，退出后恢复。
3. 标签去拥挤：近距优先、选中强制显示、非选中上限。
4. 红巨星/白矮星近景轻量差异化，不新建重型渲染器。
5. 更新过期文档状态，并忽略本地素材/工具目录。

## 非目标

- 不重写黑洞管线
- 不扩充星图目录
- 不引入打包或 WebGPU

## 验收

- 打开页面后 loading 会消失，界面可点。
- 进入/退出黑洞、脉冲星、超新星、红巨星、白矮星时时间倍率自动切换并恢复。
- 密集星图层标签更少重叠，选中目标始终可见。
- 红巨星与白矮星近景视觉可区分。
- `node --check` 与目录校验通过。
