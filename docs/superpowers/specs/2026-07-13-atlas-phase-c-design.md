# 星图阶段 C：深空尺度扩展设计

## 目标

均衡扩充本星系群与宇宙近邻两个大尺度图层，使银河系之外的探索路线从单个星系自然过渡到星系群、星系团和大尺度结构。阶段 C 只扩充目录数据，不改变星图渲染架构。

## 范围

新增 10 个不重复目标：本星系群 5 个，宇宙近邻 5 个。

### 本星系群

- IC 1613：本星系群不规则矮星系
- NGC 6822：巴纳德星系，不规则矮星系
- WLM：孤立的不规则矮星系
- 仙女座 II：仙女座卫星矮星系
- 仙女座 III：仙女座卫星矮星系

### 宇宙近邻

- NGC 253：雕刻室星系群代表星系
- M82：M81 星系群中的星暴星系
- NGC 5128：半人马座 A，活动星系
- M87：室女座星系团中央巨椭圆星系
- 本超星系团方向：室女座超星系团/本超星系团尺度参照

不重复添加已经存在的星系群或星系团目录项。新增的单个星系用于给现有星系群和星系团提供代表性观测节点。

## 数据设计

- 本星系群目标使用 `atlasMap: 'local-group'` 和现有 `galaxy` 分类。
- 宇宙近邻中的单个星系使用 `atlasMap: 'cosmic-neighborhood'` 和 `galaxy` 分类；本超星系团方向使用 `supercluster`。
- 每个目标提供唯一 ID、双语名称、距离、近似银经银纬、颜色、尺寸、类型和科学说明。
- 继续使用现有 `scaleCatalogDistance()` 压缩不同距离尺度；不新增距离公式或距离壳，除非浏览器验证显示现有壳层无法容纳目标。
- 单个星系不提供 `systemLayout`；大尺度方向标必须明确说明不是实体边界或精确三维模型。

## 交互与数据流

1. `CELESTIAL_CATALOG` 提供阶段 C 的 10 个目标。
2. `StarAtlas.rebuild()` 使用现有星系和大尺度结构视觉创建对象。
3. 搜索和类型筛选自动包含新增目标。
4. `selectCatalogEntry()` 根据 `atlasMap` 自动切换到本星系群或宇宙近邻，完成飞入和信息面板展示。

## 验收标准

- 总目录从 80 增加到 90。
- `local-group` 从 10 增加到 15，`cosmic-neighborhood` 从 10 增加到 15。
- 所有新增 ID 唯一，且图层与分类正确。
- `node scripts/validate-catalog.cjs` 通过并检查阶段 C 目标存在性与图层归属。
- `node --check js/planetData.js`、`js/atlas/starAtlas.js`、`js/solarSystem.js` 通过。
- 浏览器至少验证两个本星系群目标、两个宇宙近邻目标和一个大尺度方向标。
- 四层切换、搜索、飞入、信息面板和标签密度正常，没有空白场景或控制台错误。
- 同步更新 `README.md`、`开发日记.md` 与 `NEXT_STEPS.md`。
