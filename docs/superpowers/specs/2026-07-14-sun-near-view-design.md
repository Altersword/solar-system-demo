# 太阳近景专用模型设计

## 目标

保留日常场景轻量太阳，点击太阳进入近景后切换高细节模型。

## 范围

### 远看
- 继续使用 `SolarBodies.createSun()` 的轻量球体 + 贴图 + 单层光晕
- 仅保证总览流畅，不加载近景高细节资源

### 近景
- 新增 `js/specials/sunRenderer.js`
- `PLANET_DATA.sun.effectType = 'sun'`
- `SpecialBodyFactory` 路由 `sun`
- `FocusController` 支持太阳近景 bloom / 相机 / 时间倍率
- 太阳信息面板显示“近景观测”按钮

### 视觉
- 光球：米粒组织、黑子、亮斑
- 色球：橙红边缘层
- 日冕：大而淡外晕
- 活动：慢自转、轻脉动、少量日珥亮丝
- 弱耀斑闪烁，无脉冲星式射束

### 性能
- 高细节仅近景启用
- 退出近景完整 dispose
- 不 ray-march，面向集显

## 验收
- 远看太阳仍轻量
- 点太阳可进近景并看到分层结构
- 返回后无残留 bloom / 对象
- 与红巨星视觉语言明显不同
