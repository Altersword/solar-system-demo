# 太阳系与近邻星图

一个基于 Three.js 的天体可视化 demo。项目从原来的太阳系模型扩展为“太阳系轨道层 + 近邻恒星/银河系地标层”：中心区域展示太阳、行星、主要卫星、矮行星和哈雷彗星，外层展示若干真实近邻恒星系和深空方向标。

## 功能

- 太阳、八大行星、主要卫星、谷神星、冥王星、阋神星和哈雷彗星的 3D 可视化
- 基于开普勒轨道元素的近似公转位置计算
- 小行星带、柯伊伯带粒子带、行星自转、轴倾角、环系统和大气辉光
- 近邻恒星系标记：半人马座 α、巴纳德星、天狼星、波江座 ε、南河三、天仓五、织女星、TRAPPIST-1、格利泽 581、天鹅座 61、牛郎星等
- 深空/银河系方向标：昴星团、毕星团、猎户座大星云、银河系中心方向、半人马座 ω / 杜鹃座 47 等
- 银河系星云与特殊天体：蟹状星云、鹰状星云、礁湖星云、三裂星云、船底座星云、玫瑰星云、螺旋星云、环状星云、仙后座 A、参宿四、心宿二、参宿七、天津四、北极星、船底座 η
- 特殊天体类型观测：红超巨星、红矮星、白矮星、脉冲星/中子星、恒星级黑洞、超大质量黑洞、超新星遗迹
- 红巨星近景：独立 `RedGiantRenderer`，强调大气、对流颗粒、慢脉动与恒星风
- 白矮星近景：独立 `WhiteDwarfRenderer`，强调小而极亮核心、强 bloom 与细环，不加喷流
- 太阳近景：独立 `SunRenderer`，远看保持轻量球体，近景切换光球/色球/日冕与日珥结构
- 太阳系近景阶段 1：行星 / 矮行星 / 卫星 / 哈雷均可进入近景，由 `SolarSystemFocusRenderer` 按类型生成
- 太阳系近景阶段 2：地球、火星、木星、土星、月球、哈雷具备更强个性化特征
- 近景高细节贴图：岩质环形山、气态云带/风暴、地球海陆云层，气态行星另有纹理云壳
- 本星系群星图：大麦哲伦云、小麦哲伦云、仙女座星系、三角座星系、M32、M110、IC 10、天炉座矮星系、狮子座 I
- 恒星系统详情：成员星、白矮星伴星、尘埃盘、确认/候选系外行星和科学备注
- 恒星系统微缩视图：点击半人马座 α、天狼星、TRAPPIST-1、格利泽 581 等目标后，在信息面板显示压缩轨道结构
- 3D 系统展开：点击带有系统结构的近邻恒星后，场景中会在目标旁展开小型轨道盘并平滑移动相机
- 展开视图支持“返回星图”，可单独关闭轨道盘并回到整体视角
- 三种显示模式：观测比例、真实距离感、近邻星图
- 四层星图：太阳邻域、银河地标、本星系群、宇宙近邻（共 50000 个目录目标）
- 太阳邻域阶段 A：新增半人马座 α B、鲁坦 726-8、罗斯 128、蒂加登星、格利泽 667、开普勒-186、开普勒-452、LHS 1140、格利泽 1132、HD 219134 等近邻恒星与系外行星研究目标
- 银河系阶段 B：新增猎户臂/盾牌-半人马臂/核球方向标、M13/M3 球状星团、NGC 604/NGC 3603 恒星形成区、WR 104、手枪星和船帆座超新星遗迹

## 黑洞近景渲染进度

- 黑洞近景已经从单一平面特效升级为多层 3D 观测模型：事件视界、倾斜吸积盘、等离子体云、光子环、透镜弧和尘埃层分离渲染。
- 吸积盘 shader 现在包含径向温度梯度、湍流扰动、团块结构、引力红移近似和随相机方向变化的多普勒增亮。
- 近景中加入了被引力弯曲的背景星光弧，以及随相机距离/倾角变化的专属 bloom/眩光叠层，用于模拟高动态范围观测画面。
- 黑洞近景会临时提升渲染像素比，并使用更高分辨率的柔光粒子贴图与更密的几何采样，减少像素块和锯齿感。
- 新增近屏 ray-bending shader 层，用连续片元计算补充引力弯曲光场、爱因斯坦环和透镜化背景星弧，作为未来专用黑洞渲染器的过渡。
- 新增近屏相对论吸积盘采样层，将盘面亮度、湍流、上下透镜像、光子环、多普勒增亮和引力红移放进连续 shader 计算，进一步减少拼接感。
- 当前黑洞近景已切换为统一近屏 shader pass，将 ray-bending、吸积盘、透镜星弧、bloom 和曝光压缩合并到同一片元管线中，旧分离 pass 保留为回退方案。
- 当前仍是视觉/物理近似，不是完整 Kerr 测地线追踪、辐射转移或 GRMHD 数值模拟。
- 后续可以将“调用更多系统资源”的重型渲染作为可选模式，而不是默认路径；默认优先把浏览器内 WebGL 管线做到最优。

## 本地运行

在项目根目录启动静态服务器：

```bash
python -m http.server 4173
```

然后打开：

```text
http://127.0.0.1:4173/
```

## 控制

- 空格：暂停/播放；界面隐藏时优先恢复界面
- `R`：重置视角
- `L`：显示/隐藏标签
- `O`：显示/隐藏轨道
- `S`：显示/隐藏近邻星图
- `E`：增强/简化视觉特效
- `H`：隐藏/恢复界面，适合沉浸式近景观测；隐藏后也可按 `Space` 恢复
- `P`：切换左键拖拽模式。默认左键旋转；开启后左键平移空间位置、右键旋转视角
- `Esc`：界面隐藏时优先恢复界面；否则关闭信息面板
- `+` / `-`：加速 / 减速
- 左侧“星图层”按钮：在太阳邻域、银河地标、本星系群、宇宙近邻之间切换

## 科学与比例说明

- 太阳系天体使用真实物理数据和近似开普勒二体轨道，但半径与距离都经过可视化压缩，不是同一真实比例。
- 近邻恒星、银河地标和本星系群目标不模拟绕太阳运动；它们按距离、银经、银纬映射为星图方向标。
- 银河系中心距离过大，因此在模型中作为“方向标”显示，不按真实比例展开。
- 外星系距离使用强压缩尺度显示，只表达方向和相对远近，不表达真实体积或角大小。
- 宇宙近邻层进入星系群/星系团/超星系团尺度，显示的是大尺度节点与方向，不再展示恒星或行星细节。
- 恒星系统微缩视图同样是可读性示意图：轨道间距、双星距离、尘埃盘大小不按同一真实比例。
- 3D 系统展开使用同一套压缩数据，仅用于帮助理解系统结构；不代表真实空间尺度。
- 程序化纹理不是 NASA 实拍贴图，只用于表现颜色、云带、冰质或岩质视觉特征。
- 模型不包含完整行星间摄动、岁差、真实历表或最新天体测量修正。
- 当前只加入了非常保守的相对论近似：水星轨道使用约 43 角秒/世纪的广义相对论近日点进动参数。模型仍不包含完整 N 体摄动、真实历表、光线追踪或广义相对论磁流体模拟。
- 黑洞、脉冲星、超新星等效果是基于已知物理现象的可视化示意，不代表完整辐射转移、等离子体或引力透镜数值解。
